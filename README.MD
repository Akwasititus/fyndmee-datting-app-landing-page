# Fynd Mee website

Next.js marketing site for Fynd Mee.

Run `npm install` and `npm run dev` to develop locally. Use `npm test`, `npx tsc --noEmit`, and `npm run build` to check changes.

Vanessa uses Groq's free API with FAQ fallback. See [Vanessa setup](docs/vanessa.md) for server environment variables, privacy settings, and validation steps.
